# data

천안 지역 공공 데이터를 전처리해서 코칭에 쓸 수 있는 형태로 만드는 Python 코드입니다.

## 사용하는 데이터

| 데이터 | 출처 | 쓰임 |
|---|---|---|
| 수치표고모델(DEM) | 국토지리정보원 국토정보플랫폼 | 도로 경사 계산, 내리막 구간 찾기 |
| 표준노드링크 | 국가교통정보센터 | 제한속도, 교차로 위치 |
| 무인교통단속카메라 | 공공데이터포털 | 추가 감속 지점 |

## 폴더 규칙

- `raw/` : 내려받은 원본 데이터를 두는 곳. 용량이 커서 **GitHub에 올라가지 않습니다.** (각자 직접 만들어서 사용)
- 전처리 결과(감속 지점 등)는 MongoDB에 저장합니다.

## 주의할 점

- DEM은 땅 표면 높이라서 **다리·터널 구간은 경사가 이상하게 나옵니다.** 앞뒤 고도를 이어서 보정해야 합니다.
- 천안 지역만 잘라서 처리합니다.

## 시작하기

```bash
cd data
python -m venv .venv
.venv\Scripts\activate          # 맥: source .venv/bin/activate
pip install -r requirements.txt
```
